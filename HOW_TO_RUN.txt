Tour Ceylon — How to Run from the Beginning
===========================================

Prerequisites
-------------
Install these first:

1. Node.js (v18+) — https://nodejs.org
2. Python (3.10+) — https://python.org
3. PostgreSQL — https://postgresql.org


First-Time Setup (do once)
--------------------------

Step 1 — Database
1. Open pgAdmin or psql
2. Create a database named: travel_app

Step 2 — Backend
Open Command Prompt or PowerShell:

  cd D:\ceylon\ceylon\backend
  copy .env.example .env
  python -m venv .venv
  .\.venv\Scripts\activate
  python -m pip install -r requirements.txt

Edit .env if your Postgres password is not "password":

  DATABASE_URL=postgresql+psycopg2://postgres:YOUR_PASSWORD@localhost:5432/travel_app

Seed the database:

  python scripts\travel\apply_schema.py
  python scripts\travel\seed_data.py
  python seed_sos_data.py
  python scripts\wellness\seed_data.py

Step 3 — Frontend

  cd D:\ceylon\ceylon\frontend
  npm install
  npm run install:all


Run the App (every time)
------------------------
Use two terminals.

Terminal 1 — Backend:

  cd D:\ceylon\ceylon\backend
  .\.venv\Scripts\activate
  python run.py

Wait until it is running on port 5002.
Check: http://127.0.0.1:5002/api/health

Terminal 2 — All frontends:

  cd D:\ceylon\ceylon\frontend
  npm run dev


Open in Browser
---------------
Travel (itinerary planner) : http://localhost:5180
Tourist SOS                : http://localhost:5175
Police dashboard           : http://localhost:5176
Wellness matcher           : http://localhost:5181
Wellness admin             : http://localhost:5181/admin


Optional — Run One App Only
---------------------------
  npm run dev:travel
  npm run dev:tourist
  npm run dev:police
  npm run dev:wellness


If Ports Are Busy
-----------------
npm run dev clears stale processes on ports 5174–5176, 5180 and 5181 automatically.
If something still fails, close old terminal windows and run npm run dev again.


Quick Checklist
---------------
[ ] Postgres is running and travel_app database exists
[ ] Backend .env is configured
[ ] Schema + seed scripts have been run
[ ] python run.py is running (port 5002)
[ ] npm run dev is running in frontend
[ ] Open http://localhost:5180 for the travel app
[ ] Open http://localhost:5181 for the wellness matcher
